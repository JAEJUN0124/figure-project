# Brief: FigureVault 데이터 확보 방안

## 질문

FigureVault(피규어 컬렉션 관리·가격 추적 웹 서비스)가 약관·기술 문제 없이 가격 이력과 카탈로그 데이터를 확보할 수 있는 방법은 무엇인가?

## 목적

README(기획서)의 데이터 소스 구성을 확정하거나 다른 안으로 바꾸기 위한 판단 근거. 구현 착수 전 단계.

## 제약

- 개인 프로젝트, 개발자는 한국 거주 (해외 서비스의 개발자 키 발급 가능 여부가 조건)
- 비용: 무료 또는 소액. 유료 안은 가격을 함께 기록
- 핵심 기능은 "신품 판매가를 일 단위로 수집해 장기 보관·그래프 표시". 이것을 약관이 막으면 그 소스는 탈락
- 봇 차단 우회가 필요한 수집 방식은 채택하지 않음
- 기준일: 2026-11-26. 2026년에 바뀐 사항(라쿠텐 API 개편, 네이버 쇼핑 검색 API 종료)을 반영

## 깊이

standard (조회 약 30~36회, 3개 그룹으로 분담)

## 판정할 주장

| # | 주장 | 그룹 |
|---|---|---|
| C1 | Yahoo! 쇼핑 상품검색 API(v3)의 약관은 받아 온 가격 데이터를 서버에 장기 보관(일 단위 이력 축적)하는 것을 허용한다 | A |
| C2 | 라쿠텐 웹 서비스(2026 개편 후)의 약관은 가격 데이터의 장기 보관을 허용하고, JAN 코드로 상품을 특정해 가격을 조회하는 API가 있다 | A |
| C3 | 한국 거주 개인이 Yahoo! JAPAN 개발자 네트워크와 라쿠텐 웹 서비스의 API 키를 발급받을 수 있다 | A |
| C4 | Amazon(PA-API / Creators API) 또는 Keepa API로 amazon.co.jp 피규어의 가격 이력을 제3자 서비스가 합법적으로 얻어 표시할 수 있다 | B |
| C5 | 하비샵(AmiAmi, Hobby Search, HobbyLink Japan, Solaris Japan 등)이나 가격비교 사이트(価格.com 등) 중 가격 추적에 쓸 수 있는 공식 API·제휴 상품 피드를 제공하는 곳이 있다 | B |
| C6 | 국내 공식 소스(쿠팡 파트너스 API, 다나와 등) 중 피규어 판매가를 조회하고 보관할 수 있는 곳이 있다 (네이버 쇼핑 검색 API 종료 여부 재확인 포함) | B |
| C7 | MyFigureCollection은 API, 데이터 내보내기, 또는 허가 절차를 통해 카탈로그 데이터의 제3자 이용을 허용한다 | C |
| C8 | 작품·캐릭터·제조사·JAN이 구조화된 피규어 카탈로그를 자유 이용 조건으로 얻을 수 있는 소스가 있다 (Wikidata, 제조사 공식 사이트, 오픈 상품 DB 등) | C |

예상: C1·C2는 조건부이거나 거짓일 가능성이 있고, C7은 거짓일 가능성이 높다.

## 가정

- "장기 보관"은 최소 1년 이상의 일 단위 가격 스냅샷 저장을 뜻함
- 서비스는 비영리·소규모로 시작하지만, 공개 웹 서비스로 다른 사용자도 쓸 수 있음
